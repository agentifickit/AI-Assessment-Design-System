## Shell anatomy (05, 06, 07)

- **Sidebar** 240 wide, `--surface`, right hairline `--neutral-200`. Brand mark 32px `--orange-500` square (`--radius-sm`) with wordmark. Nav items 40px tall; active item `--surface-subtle` fill with an `--orange-500` dot, `--radius-sm`. Pinned to the bottom: `Avatar` initials on `--orange-200`, name (13 Semi Bold), "Owner, Acme Corp" (12 `--fg-muted`), "Sign out" text link.
- **Top bar** 80px, `--surface`, bottom hairline. Eyebrow is the organization name (11 Semi Bold `--orange-700`, +2% tracking), title 24 Semi Bold, one primary `Button` right-aligned.
- **Content** `--space-40` padding on `--canvas`. 05 and 06 centre their card; 07 top-aligns the table.
- One organization only. The org name is static text; there is no switcher (B2).

## State notes for PLU-083 and PLU-084

- **05 empty state** is the entry to the wizard (PRD-02 "Empty"). Its CTA reads "Create your first assessment", deliberately different from the top-bar "Create assessment".
- **06 permission denied** copy is content-free by design: no record id, name or foreign organization appears (AC-02). The shell stays rendered so the user is not stranded; the page title falls back to the resource type ("Assessment"), never the record's own title.
- **07 table** columns: Assessment (fills), Role, Status `Badge` (Published success, Draft neutral, Closed danger), Invited, Completed, Updated. Invited and Completed are separate right-aligned numeric columns. Footer: "4 assessments. Comparison unlocks once a report is human-verified." (PRD-04 gate).
- **Not drawn, out of PLU-087 scope:** Candidates and Roles pages; the "no role assigned, contact us" state (reuse the 06 card with a neutral `Badge`); loading and skeleton states.

## Copy rules

- Never use the middle dot "·" as a separator in UI copy. Write a sentence, use a comma, or split into columns.
- Refusals never mention the record or the other organization.
